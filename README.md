# Alchemy Magic: downloads

This repository holds the installers for **Alchemy Magic**, the AI app that chats, codes and uses its own browser to get things done.

- **Download:** grab the newest `Alchemy-Magic-Setup-x.y.z.exe` from [Releases](https://github.com/SkyNexusGH/Alchemy-Magic-Releases/releases/latest)
- **Website:** https://alchemy.fivenova.org/magic/
- **Updates:** Alchemy Magic checks here by itself and updates in the background.

Windows 10 and 11 (64-bit). Made by SkyNexusHD (SNHD) and FiveNova.
